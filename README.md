# analisis-secuencias-biologicas
# Análisis Bioinformático de Secuencias Biológicas

**SeqTool Box** es una herramienta modular desarrollada en R para el procesamiento y análisis de secuencias de ADN en formato FASTA. Permite automatizar cálculos de composición nucleotídica, contenido GC y traducción de secuencias a aminoácidos.

## Funcionalidades

- **Procesamiento FASTA:** lectura y extracción de secuencias de ADN.
- **Análisis nucleotídico:** cálculo de longitud, frecuencia de bases y porcentaje GC.
- **Traducción genética:** conversión de secuencias codificantes de ADN a aminoácidos.
- **Generación de reportes:** exportación de resultados para su posterior interpretación.

## Estructura del proyecto

| Directorio | Contenido |
|---|---|
| `data/` | Secuencias FASTA de entrada |
| `scripts/` | Módulos de análisis desarrollados en R |
| `results/` | Resultados y reportes generados |
